# C2.2.1 Zero-Prerequisite Installer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a clean Arcanum clone installable on supported Linux/macOS/Windows hosts without a preinstalled Python ≥3.12, while preserving every skill, agent, integration, and the canonical shared-room architecture.

**Architecture:** Thin OS-specific bash/PowerShell bootstrap layers download and verify a pinned standalone CPython archive, install it under `ARCANUM_HOME`, then run the existing Python installer engine with that interpreter. The engine's stages and safety rules stay intact; new explicit verification covers the five Arcanum skills, 88-skill registry, and release alignment.

**Tech Stack:** Bash, Windows PowerShell 5.1-compatible PowerShell, Python stdlib bootstrap engine, GitHub Releases API, bun, pytest.

**Spec:** `docs/superpowers/specs/2026-11-26-c2.2.1-zero-prerequisite-installer-design.md`

## Global Constraints

- Repository remains independent and not a fork; no old-fork runtime dependency.
- Preserve all five agents: `hackbot-lead`, `recon-agent`, `hunt-agent`, `validate-agent`, `report-agent`.
- Preserve exact five Arcanum skills: `api-fingerprint-caido`, `interceptor`, `js_analysis`, `lazy_chunk_downloader`, `say_hello`.
- Preserve 83 vendored Claude BugHunter skills at upstream `6a530fb3149c8c34d3ba0eb31b4eb431e91da648`; total registry = 88.
- Preserve `(workflow_id, target_id) -> room_id`; installer never seeds rooms or targets.
- `--check` remains completely write-free and never downloads/extracts a runtime.
- Windows PowerShell 5.1 is in scope; PowerShell 7 is optional.
- Windows ARM64 remains `UNSUPPORTED` for full install because Maestro v1.1.1-RC has no matching artifact.
- Never embed credentials, never delete migration backups or the old fork, never overwrite unmodified-failed user skill changes silently.

## Review Focus

- Missing Python on host → bootstrap pins, downloads, verifies, and installs; no unverified remote code.
- Missing download/hash/extract utility → `UNSUPPORTED` with manual fallback, not a false success.
- `--check` with no Python → write-free status report only.
- Locally modified skill during upgrade → preserved with conflict report; no silent overwrite.
- Release tag mismatch → publish `v0.1.1` at exact tested SHA; never rewrite `v0.1.0`.
